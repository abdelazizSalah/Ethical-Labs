# btu - A University Student Management System

This software is a basic implementation of the student management system of BTU Cottbus-Senftenberg.
Its aim is to be *almost* as secure as the real thing.

## Folder Structure

This program contains the following folders and files:

| Folder  | Purpose                                    |
|---------|--------------------------------------------|
| build   | binary files created by compilation        |
| include | C++ Header Files and Protoype declarations |
| src     | Source Code, i.e. C++ files                |
